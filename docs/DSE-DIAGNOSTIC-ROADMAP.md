# DSE 中文情报侦察站：开发路线

## 产品边界

本产品定位为“中文信息处理过程诊断”，不是 DSE 等级预测、完整模拟卷或医学诊断。

第一版必须持续满足以下原则：

- 把“尚未学过”与“底层能力卡点”分开；
- 保存首次答案、最终答案、耗时、提示层级和修改次数；
- 所有结论附可回看的作答证据；
- 简体理解、繁体阅读和书写交付分开评价；
- AI 仅辅助开放答案分析，不直接决定正式等级或学习障碍；
- 题库含义变化时升级 `templateKey`，不覆盖历史版本。

## 当前已落地

### 产品入口

- 军事情报终端风格首页；
- 两场任务、信息处理链和九维能力模型说明；
- 首场任务入口、简繁显示控件和任务简报。

### 第一场：信息侦察

- 12 道诊断题，覆盖电台解码、指令拆解、情报研判和古文密令；
- 语音播放、单选、短答和两级动态提示；
- 熟悉/陌生题材及简体/繁体材料标记；
- 自动保存、匿名 access token 续做；
- 首次答案、最终答案、首次耗时、总耗时、提示和修改记录；
- 学生版九维报告、主要卡点、证据和下一项技能。

### 后端

- 独立 `DiagnosticAttempt` / `DiagnosticAnswer` 数据模型；
- 题库答案不下发浏览器，评分只在服务端执行；
- 规则评分与诊断报告接口；
- 与原有 AI 素养问卷数据完全隔离。

## 后续开发顺序

### P1：首场内容校准

目标：让当前 12 题形成可验证、可调整的诊断样本。

- 增加到约 20 道客观或半客观题、6 道阅读简答；
- 为每道题标注预期耗时、阅读难度、词汇难度和 DSE 能力映射；
- 加入真实录音文件，保留浏览器语音合成作为降级方案；
- 保存跳题、页面离开、音频播放次数与阅读停留时间；
- 后台提供单题正确率、提示改善率、耗时分布和干扰项分布；
- 通过小样本访谈修订题干，不直接用正确率判断题目难度。

验收重点：

- 同一能力至少有 3 条独立证据；
- 题目不能依赖八年级尚未教授的 DSE 专门格式；
- 提示只暴露策略，不直接给出答案；
- 简繁材料在词汇、长度与句法难度上可比较。

### P2：第二场“行动报告”

目标：比较口述、提纲、键盘短答和手写交付之间的损耗。

- 六格任务板：身份、对象、目的、文体、必答内容、语气；
- 缩小版实用写作，支持过程保存；
- 浏览器录音上传、播放和人工转写修订；
- 提纲编辑器；
- 手写计时、照片上传、图片方向修正；
- OCR 作为辅助识别结果，原图始终保留；
- 口述—提纲—手写内容对齐比较。

建议新增的数据对象：

- `DiagnosticArtifact`：audio、outline、handwriting、ocr_text；
- `ArtifactReview`：人工修订文本与审核状态；
- 对象存储只保存路径和元数据，数据库不存大型二进制文件。

### P3：家长与研究者报告

目标：让结论可追溯，并避免单一总分误导。

- 独立家长查看码，可撤销、可重新生成；
- 九维雷达图与 DSE 试卷能力映射；
- 首次答案—提示—修改后的过程回放；
- “不会 / 会但来不及 / 提示后可修正”的证据分组；
- 熟悉与陌生题材、简体与繁体的配对比较；
- PDF 导出；
- 专业读写评估建议必须采用条件式表述，并附限制声明。

### P4：AI 辅助分析

目标：减少开放答案人工整理成本，不替代证据与复核。

- 仅通过 `src/lib/integrations/conversation-adapter.ts` 接入模型；
- 使用固定 rubric 分别评价结论、文本证据、关系解释；
- 输出结构化 JSON、证据句和置信度；
- 低置信度、OCR 低质量或口述转写冲突时进入人工复核；
- 保存 prompt 版本、模型版本和人工修订，不静默覆盖历史判断；
- 家长报告中的每条 AI 结论必须链接到具体作答证据。

### P5：训练方案接口

目标：诊断稳定后再生成 12 周训练处方。

- 以卡点、可用时间和兴趣题材作为输入；
- 每周只设置一个主要能力目标；
- 同一策略跨熟悉与陌生题材迁移；
- 训练后使用平行题复测，不重复原题；
- 处方效果和初始诊断分开存储，避免训练数据污染诊断基线。

## 分析模型校准

当前规则适合产品原型，不适合作为已验证量表。进入对外使用前需要：

1. 由中文教育者复核题目和 rubric；
2. 记录样本的年龄、学习语言和课程背景，但不用于排名；
3. 检查同维度题目的一致性及题材偏差；
4. 建立耗时参考区间，不能沿用当前原型的固定 75 秒阈值；
5. 对规则结论与人工盲评做一致性检查；
6. 明确最小证据数，证据不足时必须显示“不下结论”。

## 安全与隐私

- 学生端默认匿名，不采集姓名；
- 音频和手写照片属于敏感学习资料，应设置保留期和删除入口；
- 家长码与学生续做 token 分离；
- 下载报告前再次校验查看权限；
- 管理后台记录查看与导出审计日志；
- 禁止在日志中输出 token、音频地址或手写图片签名 URL。
